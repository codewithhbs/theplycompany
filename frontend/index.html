Who We Are

Built On timber, Run On Trust

Pradeep Timber Enterprises is Delhi's one-stop solution for every plywood need. Whether it's structural plywood, PVC boards, HDHMR, MDF, mica, adhesives or hardware — hinges, L-drops, telescopic channels, screws — we stock it all, so you never have to run between five different shops for one project.

Beyond boards, we supply premium timber — Flexi Ply, Shuttering Ply, Pine Wood Baton, Meranti, Sagwan, Ivory Coast and Teak wood — and back it all with skilled carpentry services: chaukhat making, randa on wood, general carpentry and professional door installation.
